## 已退出的旧编制方案

| 旧方案 | 本分支现行口径 |
|---|---|
| 营作为常规独立单位直接接入纵队／协调军 | 营固定隶属旅，旅为最低常规组织后勤接口 |
| 二战营约800人、后备连、8门82迫、10辆1.5T加一辆0.5T | 六门82迫、六辆1.5T加一辆0.5T；后备和部分火力上收旅；营旅总员额重核 |
| 战后900／1000人营、现代每营额外30%后备连 | 人员再生归旅属后备营；旧总额和比例不套用新旅制 |
| 纵队有机12门120毫米重迫营与12辆牵引车 | 旅有机六门120重迫，纵队无固定有机火力；新增配属另计 |
| 冷战每步兵／摩步营有机HZ-47连 | 混成旅装甲营集中编制，步兵营按任务受援 |
| 机械化／现代摩步营固定有机14辆坦克连 | 旅属坦克营44辆，按任务配属BTG／CTG；14辆仍为坦克连定额 |
| 现代步兵营58辆有机核心车 | 摩步营最低44辆（含满编防空），获配完整坦克连的任务方案才为58辆 |
| OG与纵队互作同义词、单纵队自动设OG | 纵队常设、OG临时按需；具体战役已有兼任任命保留 |

旧“每营38辆”的1960年代卡车配额仅因取消营属后备连的一辆3T车而减为37辆；25辆1.5T、7辆3T、5辆0.5T，不推定删下的车辆自动成为旅后备营新有机车。
