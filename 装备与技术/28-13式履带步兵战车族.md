## 13式：强烈军方需求推动的重型IFV项目

47式APC与HZ-00共底盘，具有维护和备件优势。到2010年代，重型机步对防护、载员工作空间及数字化集成提出了新的整车需求。13式以精简后的常备履带部队为采购基础，将投资集中于前沿重型作战单位。此前88式APC采购及47式延寿的经过见[22号](22-HZ-88火力支援车与新一代通用履带底盘.md#topic-09)和[27号](27-95式轮式车族与HZ-00采购转型.md#topic-02)。

## 13式IFV的明确研发目标

| 项目 | 已锁定目标 |
|---|---|
| 标准战斗车辆类型 | 履带式步兵战车（IFV），取代重型机步排的APC＋单独FSV基本模式 |
| 研发目标下达年份 | **2013年** |
| 开始正式服役年份 | **2020年** |
| 战斗全重 | **最大30吨** |
| 车组与载员 | **3名专业车组＋7名下车机械化步兵（3＋7）** |
| 主武器 | **30毫米机关炮** |
| 反坦克导弹 | **炮塔左右各一组双联装ATGM，共四枚待发** |
| 编制定位 | 在重型机步单位实行标准战斗车辆**IFV全员化** |

标准班车采用**3＋7**配置。每个7人机步班采用**班长＋两个各3人的战斗组（1＋3＋3）**，班长与组长分工，不要求班长兼任其中一个战斗组长。13式四联ATGM的新弹种型号尚未确认，**不自动套用原75式“剑”**。

13式总体定位是**车辆为主要战斗平台、步兵为其下车节点**，强调车组独立执行火力和机动任务、下车步兵与IFV协调处理复杂地形和近距离接敌。该概念是组织和战术原则，不意味着步兵可以不具备独立指挥与战斗能力。

### 常设机械化团与排级整体换装

现代机械化团为**三个机步营＋一个团属坦克营＋一个直属弹炮结合防空连**，坦克不在每个机步营另设固定有机连。全国机步团数、逐团存续与具体番号另见23、42号。

2020年起，每排**3辆ZS-47 APC＋1辆HZ-00 FSV**逐步由**4辆BZ-13 IFV**统一替换。BZ-13同时承担原APC载员与FSV火力／通信节点任务，**不再额外加一辆HZ-00**；换装对象为前沿机步排，保障衍生车按任务和车况逐批更新。

### 每排四辆13式IFV

- **一、二、三号车**：各3名专业车组、各搭载1个完整**7人机步班**，合计21名下车班员。
- **第四辆车（排长车）**：保持完整IFV武装与专业车组，其后部载员位置用于**排部指挥终端**以及视任务搭乘的前方观察、火力协调、空军联络等专业人员。
- 排长车的任务人员、装备与原本7个载员位之间存在空间和载荷取舍；**不能直接把它当作还能无条件搭载满额7名步兵的额外步兵班**。
- 空军联络或类似专业岗位可以按行动需要进入排长车，**不确定每个排均有一名常设空军联络员**。

每连三个四车排加连部2辆，共14辆；每营三个连加营部2辆，共44辆核心装甲车。连部、营部车型尚未确定，不能将8辆指挥车辆都认定为13式；排长车外观及具体火控／数字终端工作席尺寸亦未锁定。

## 轮履支援平台分工

### 95式车族提供重型单位的轮式通用基础

2003年后形成的重型部队保障体系优先使用95式轮式底盘，通常适用于营属指挥、通信、迫击炮、救护及常规保障。需要履带通过性、防护或与重型部队伴随时再选13式衍生平台，极端重型救援任务另行论证。95式的底盘、载荷和右前动力布局见[27号](27-95式轮式车族与HZ-00采购转型.md#topic-03)。

### ZS-13与95式工兵运输车的分工

**ZS-13**以BZ-13去掉炮塔形成，是面向重型履带伴随及高威胁专业任务的特种运输车。普通战斗工兵排继续沿95式轮式路线换装，年份、配置与第751营旧装见[47号](../军制与人员/47-现代战斗工兵营与专业车辆.md#topic-04)。ZS-13的人员运输构型、生产规模和服役年份待定。

<a id="topic-04"></a>

## 2013年立项、2020年列装与后续换装

2013年，军方提出重型履带机步车族需求，议会批准采购协议，以有限的常备履带规模换取更强的单车火力、防护和数字化能力。**2020年开始列装**，过渡期间仍可使用47式APC与HZ-00，逐团换装与旧装最终退役时间待定。军改及保留机步团规模见[23号](../军制与人员/23-陆军裁军与数字化转型.md#topic-10)。

现代基本人员为三个7人班加3人排部，车组另计；本车族用三辆班车和一辆排部车承载，对应本文件保留的具体空间与任务席位边界。机摩与CE通用班排规则见[41号](../军制与人员/41-现代RTG与摩步战斗群.md)、[47号](../军制与人员/47-现代战斗工兵营与专业车辆.md)。
