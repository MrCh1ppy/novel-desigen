# 第八纵队1944北越河根突破战役档案

这是本仓库架空世界线的一次纵队级交互兵棋推演档案；与现实越南战争无关。

## 阅读顺序

1. [00-战役总结.md](00-战役总结.md)：全程时间轴、双方兵力、战役意义、最终战果与裁判可信性说明。
2. [01-逐轮战报](01-逐轮战报)：17份原始情报/战报，按时间依次浏览，保存推演时的原始记录。
3. [02-态势地图SVG](02-态势地图SVG)：15张原始公开态势图，采用SVG矢量格式，便于版本比较和后续编辑。
4. [03-裁判勘误](03-裁判勘误)：正式战果复核和最终解封复盘，说明第十七轮方位错误等问题。

## 档案使用说明

- 原始战报完整保留，包括其中后来经证实的裁判错误。请先读总结与勘误，不要将原第十七轮关于铁锋方位和日军北撤的结论视为最终事实。
- 原始封存日军秘密部署曾发生遗失后重建，重建时已知部分中国军决策；这不是严格意义的全程事前封存、双盲对抗。
- 日军最终逐人伤亡及逐件缴获清单缺失，因此未宣称“全歼”或准确缴获数量。
- 原12月16日12:55版SVG因上传接口限制未列入Git，其对应战报仍完整保留；地图其余15张均有存档。
- 不在公开仓库中上传包含裁判未来行动规则与逐轮秘密状态的JSON续档。战后已解封的敌情与裁判误差，写在总结和勘误中。
- 本文件夹是**兵棋推演过程档案**，不自动修改仓库主线正史设定。
