# 架空中国设定集

这是一套从1895年甲午战争余波开始分岔、持续到20世纪冷战后期的架空中国世界观设定。

主线并不是“现实民国强化版”，而是讨论一个更早完成国家机器现代化的中国，如何经历立宪、统一战争、东北战争、第二次世界大战、蒙古战争和冷战，并最终成为欧亚东部一个不结盟但不可忽视的独立战略极。

当前仓库同时包含历史主线、政治制度、军制、战术、装备参数、战役档案与冷战增量。大量技术细节按“已锁定 / 尚未锁定 / 废案”分层管理。

二战空军装备见：

冷战喷气发展见：

[14 冷战空军发展谱系](14-冷战空军发展谱系.md)

当前喷气机正式主线为：

**45式 → 第二代单发超音速战斗机 → 59式／歼-59**

其间不是技术空白，而是存在大量只制造约5—10架的小批验证机和试验机。

歼-59于1960年成为转折点：在此之前喷气机长期低产、以技术试验价值为主；歼-59出现后，中国才真正把主要战斗机工业能力集中到大型双发多用途平台，并停止独立发展专用喷气战术轰炸机、战术侦察机、SEAD机和独立舰载战斗机谱系。

## 正史与未定稿规则

仓库中的内容不是同等权威。

处理冲突时，基本原则是：

1. 后出的、用户明确确认的定稿覆盖旧设定；
2. 09号负责装备与弹药参数；
3. 10号负责编制；
4. 专题定稿文件优先于早期工作底稿；
5. 05号是开放问题清单，不是正史；
6. 文件中明确标注“尚未锁定”“建议”“估计”的内容不得自动升级为正史；
7. 被后续定稿覆盖的旧方案保留时，应视为沿革或废案，而不是并列有效设定。

详细冲突优先级见 [00-总览.md](00-总览.md)。

## 当前冷战空军的一句话概括

> 中国在1950年代只正式造了三代喷气作战平台，却用大量小批验证机完成技术爬坡；45式解决喷气与超音速入口，第二代把Mach 1.5级超音速变成正常作战能力，而1960年的歼-59第一次让中国认为喷气机值得成为整个空军的主体。
