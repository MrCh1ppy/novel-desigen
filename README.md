# 架空中国设定集

本仓库是一套从**1895年甲午战争余波**开始分岔、延续至21世纪的架空历史世界观。其主线是一个较早完成国家与工业体系现代化的中国，如何经历立宪、统一与世界大战，在冷战时期成为欧亚东部独立的第三极，并在2008年苏联解体后与美国共同形成**合作性两极**。

文档涵盖历史、政治、社会、军制、武器技术与战役档案。**README只负责导航；具体事实、参数和未定事项以对应专题正文为准。**

## 设定的几条主线

**历史与国际秩序：**1895年分岔后的共和国经历二战与冷战；2008年苏联解体后，中美形成合作性两极，但合作**不等于同盟**，中国也不承诺无限制海外驻军。相关资料见[00号](00-总览.md)、[08号](08-冷战时期-政治外交与80年代越南战争.md)、[36号](36-2008年苏联解体与俄罗斯政治转型.md)、[37号](37-冷战后中美合作性两极与国际秩序.md)。

**军队组织：**中国陆军围绕独立营、常设纵队司令部、任务组建的战役集群（OG）以及战役协调军组织作战。2014年现役一线骨干为**30个摩托化营、12个机械化营**，另有**15个战斗工兵营**；多轮裁军与军人职业声望共同塑造高选择性、高训练投入的野战军。见[03号](03-陆军军制.md)、[10号](10-编制.md)、[23号](23-1990年代第三次裁军、全面空气化与苏联延寿.md)、[42号](42-2014年陆军营与纵队司令部番号台账.md)。

**装备与现代战术：**05式轮式车族、ZTZ-90与“空气”系统支持机动和合成作战；标准车辆排原则上为**1辆排长车＋3辆其他车**，明确的特种排保留例外。CE营为**3个常规战斗工兵连＋1个重装工兵连**，后者含FH-47四车喷火排、PL-47四车排雷排及仅少数营实装的ZTZ-65E两车攻坚排。见[09号](09-武器装备库.md)、[10号](10-编制.md)、[21号](21-空气自动化指挥系统.md)、[41号](41-2014年摩托化BTG与CTG编制战术.md)。

**2015年霍姆斯：**韩维钧指挥霍姆斯OG，第37纵队统率5th、7th、54th、96th BTG，245th直属OG负责交通线；第751战斗工兵营集中加强54th，拥有**两辆ZTZ-65E2**。战役后期发生城区巷战、平民伤亡争议；韩维钧战后升任西北战区司令。联军总战果、具体伤亡和法律责任结论仍按专题保留未定状态。见[40号](40-2015年叙利亚反恐战争与多国军事干预.md)、[41号](41-2014年摩托化BTG与CTG编制战术.md)、[42号](42-2014年陆军营与纵队司令部番号台账.md)。
